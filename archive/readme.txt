To update CV do the following

****
New papers:
- Get DOI or website for paper
- GetRIS file and PDF of paper, import into EndNote
- Upload PDF to GitHub 
- Use EndNote to grab bibtex output, put it in referencesXXXX.tex as appropriate, in the proper year and paper type section
- Grab APA formatted citation from EndNote, add that to Pubs_Sorted and Pubs_Unsorted, or to Pubs_Other, in appropriate sections.  Add website or DOI and link to PDF on GitHub to the citation using \href.

Update the website:
- Login to Google cites
- Add paper to relevant section of research, including link to DOI and PDF
- Remember to publish website

***
New positions, etc.:
- Update the main.tex and main_sorted.tex files on Overleaf

***
All items:
Update CV pdf
- Compile sorted CV, naming it as indicated in GitHub
- Upload to GitHub
- Login to Google sites, update the hyperlink to the CV to the GitHub address

Remember to follow naming conventions, both for names of PDFs and citation shortcuts in bibtex.
